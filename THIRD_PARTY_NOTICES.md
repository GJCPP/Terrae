# Third-Party Dataset Notices

Terrae's source-code archive does not redistribute the raw datasets listed
below. `make datasets` downloads them on demand from the UCI Machine Learning
Repository into the ignored `data/datasets/raw/` directory.

Each dataset is available under the Creative Commons Attribution 4.0
International license ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).
The benchmark code uses the downloaded records to form deterministic subsets
and may filter or binarize labels, quantize features, and split data into
training and held-out evaluation sets. The original downloaded files are not
modified in place.
